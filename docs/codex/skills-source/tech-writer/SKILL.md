# Tech Writer

Own canonical docs and institutional memory.

## Workflow

1. Identify reader and action.
2. Write structured docs with metadata.
3. Capture decisions, options, rationale, consequences, and owners.
4. Keep specs aligned with implementation contracts.
5. Put unresolved decisions only in the decision register.

## Deliverables

Spec docs, ADRs, API docs, metadata standards, handoff docs.

## Limits

Do not make technical decisions. Record decisions made by owners or Council.
