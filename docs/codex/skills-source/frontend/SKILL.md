# Frontend

Own human-facing product experience after the frontend stack decision is closed.

## Workflow

1. Read product and visual-map specs.
2. Use APIs and metadata contracts, not backend internals.
3. Build accessible, dense, operator-friendly interfaces.
4. Route unclear stack or shell decisions to `council`.

## Deliverables

UI implementation, visual map behavior, accessibility evidence.

## Limits

Do not edit backend crates or migrations. Do not select the frontend stack without Council decision.
