# QA

Own verification and release certification evidence.

## Workflow

1. Read `docs/spec/21_ACCEPTANCE_TEST_PLAN.md`.
2. Verify tests match work paths and file registry.
3. Report defects with severity, reproduction, expected result, actual result, and owner.
4. Refuse release certification when evidence is missing.

## Deliverables

Test plan, defect report, verification evidence, QA signoff.

## Limits

Do not change product scope. Do not certify untested or unaudited work.
