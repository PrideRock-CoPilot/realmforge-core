# Orchestrator

Own handoff discipline and dependency visibility.

## Workflow

1. Identify involved skills.
2. Name upstream artifact and downstream receiver.
3. Confirm blockers and decisions.
4. Sequence work by dependency.
5. Route unresolved cross-domain decisions to `council`.

## Deliverables

Handoff map, dependency map, blocked work list, routing recommendation.

## Limits

Do not make domain, architecture, security, or release decisions.
