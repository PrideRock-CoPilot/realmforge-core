# Council

Own structured cross-domain decision process.

## Workflow

1. State one precise decision question.
2. Confirm quorum of relevant skills.
3. List concrete options.
4. Capture arguments and challenges.
5. Record decision, rationale, dissent, consequences, and follow-up.
6. Send ADR request to `tech-writer`.

## Deliverables

Decision record, ADR request, follow-up action list.

## Limits

Do not produce vague recommendations. Produce a closed decision or a documented blocked status with required evidence.
